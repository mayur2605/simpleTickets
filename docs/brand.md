# SimpleTickets brand foundation

Status: burnt-orange accent selected by the user; supporting palette applied to prototype.

An independent identity for an email-first IT workspace. Allcheck Services is not the app brand. Existing allowed email domain and support mailbox remain operational settings.

## Palette

| Role | Value | Usage |
| --- | --- | --- |
| Burnt orange | #B54720 | Primary action, selected navigation, brand mark |
| Pearl | #F7F7F5 | Workspace |
| White | #FFFFFF | Interactive content surfaces |
| Graphite | #242424 | Primary text |
| Secondary graphite | #62625F | Supporting text |
| Silver | #E3E3DF | Nonessential separators |

Hover orange: #963916. Selection tint: #FBEDE7. Error red: #A92E32. Resolution green: #37664B. Status labels always carry text, not only color.

## Measured contrast

- Primary action: #B54720 on #FFFFFF, 5.4:1.
- Body: #242424 on #F7F7F5, 14.47:1.
- Secondary text: #62625F on #F7F7F5, 5.71:1.
- Selected label: #963916 on #FBEDE7, 6.35:1.

These measurements cover the named token pairs, not a complete accessibility audit. Silver separators are decorative; use Fluent control borders and explicit focus outlines for interactions.

## Typography and composition

Locally bundled Geist at weights 400, 500 and 600. Brand heading 38 px desktop / 34 px compact. Reply body 14 px. Ticket titles 12 px with secondary metadata 10–11 px; increase further if review finds these too small. No generic system font as the primary face.

Light silver navigation and pearl workspace replace the navy sidebar. The signature is a burnt-orange ticket mark and restrained orange selection. Keep the operational queue central, with no decorative imagery or promotional cards. This is an Apple-inspired web app, not native Apple UI or an Apple-affiliated brand.

Regular: navigation | ticket queue | team workload.
Compact: navigation → heading and summary → scrollable ticket queue → team workload.

Keep existing workflows and Fluent controls. Use short feedback transitions, respect reduced motion, and offer higher-contrast overrides. No Liquid Glass imitation is needed for this screen.

## Review rationale

The previous palette lacked a clear independent identity, and some metadata was too small/light. The new direction places brand expression in accent and typography while improving readability. Removed the organization block and decorative date. Native macOS menu-bar conventions do not apply to this browser app.
